## 차단 3건

- **[API-01]** FD 복제 리다이렉트(`2>&1`) 하나로 **읽기 전용 명령이 소스 쓰기로 오판**됐다.
  뿌리는 리다이렉트 정규식이 아니라 **세그먼트 분해**였다 — `&` 가 분해 기준이라 `2>&1` 이
  `1` 이라는 가짜 세그먼트를 만들고, 그 머리가 「모르는 명령」으로 분류돼 `mutating` 을 세웠다.
  `maskNonCommandText` 로 fd 복제·따옴표 heredoc 본문을 **길이 보존 마스킹**(길이가 달라지면
  cd 추적이 어긋난다), `cd`·`pushd` 를 `READ_ONLY_HEADS` 에 추가, 자기해제 가드 셋을
  **줄 기반**(`runsHarnessWith`)으로. 과차단 7/12 → **0/12**, 관통 0/8 유지.
- **[OPS-01]** 저널이 손상돼도 state.json 이 멀쩡하면 배너·deny 사유·Stop 가드 어디에도
  신호가 없었다. 세션 시작에서만 저널 건강을 보고(매 훅은 비용 때문에 안 본다),
  `Degraded.stateDamaged` 로 「재생 중」과 「이력을 못 믿는다」 문구를 갈랐다.
- **[OPS-02]** 번들 부재 시 훅이 조용히 exit 0 해 **강제가 꺼지는데** `doctor` 는 `ok:true`.
  `bin/harness` 의 catch 가 `hook-errors.log` 에 한 줄 남긴다 — `doctor` 는 이미 그걸 센다
  (새 통로를 만들지 않고 끊긴 곳만 이었다).
