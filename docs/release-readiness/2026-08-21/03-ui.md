# ③ 출력 표면 (CLI 재해석 — media-adapters.md)

GUI 가 없으므로 「UI·접근성」을 **CLI 출력 계약**으로 번역했다: TTY/비TTY 분기 · NO_COLOR ·
파이프 안전 · 비ASCII.

| 항목 | 실측 |
|---|---|
| ANSI 이스케이프 | **0개** — 색을 아예 쓰지 않는다 |
| `NO_COLOR=1` | 출력 md5 동일(무영향, 색 미사용이라 정상) |
| 비TTY stdout | `status`·`gate status`·`doctor` 전부 **JSON.parse 성공** |
| 파이프 조기 종료 | `report rtm \| head -1` 에서 EPIPE 크래시 없음(exit 0) |
| 비ASCII 경로 | `유니코드🚀.ts` 입력에 훅 exit 0 |
| 초장문 입력 | 9000자 경로에 훅 exit 0 |
| TTY 대기 | `hook` 은 `process.stdin.isTTY` 를 보고 **사람이 손으로 실행해도 멈추지 않는다** (`core/src/cli.ts:107`) |

근거: `evidence/contract.log` · `evidence/e2e.log`. 결함 0 → 대장 `UX-46`.

**보지 않은 것**: 터미널 폭 기반 줄바꿈(고정폭 가정 없음을 코드로만 확인), 스크린리더.
