못 박는다. **결과를 보고 기준을 낮추지 않는다.** 낮춰야 하면 시각·사유를 남긴다.

| 항목 | 현재 | 4.8 의 조건 (전부 measured) |

| 2 실효성 | 3.5 | **모델이 자연히 가는 우회 경로 전부 deny** — Bash 리다이렉트·heredoc·tee·touch·sed -i·cp/mv 로 (a) 설계 트랙 소스 (b) `.harness/` 코어 파일 (c) `--force` 에 도달 불가. 저널 위조 후 `doctor` 가 **탐지** |
