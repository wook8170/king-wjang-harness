  구동했다 — Claude Code 가 실제로 그 JSON 을 어떻게 넘기는지(필드 누락·추가·타임아웃 10초)는

  Claude Code 가 붙은 상태에서의 handshake·타임아웃·재기동은 보지 않았다.
