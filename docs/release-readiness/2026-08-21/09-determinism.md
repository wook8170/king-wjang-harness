## 설명 못 하는 실패 0 — 하지만 결정적이지 않은 자리가 하나 있다

`new Date()` 는 14곳에서 쓰인다. 대부분 타임스탬프 기록이라 무해하지만 **한 곳은 결함의
직접 원인**이다: `gate.ts:134` 가 승인 시각을 자체 `new Date()` 로 찍고, 같은 사건의 저널
이벤트는 `events.ts:25` 가 **별도의** `new Date()` 로 찍는다. 두 값이 밀리초 단위로 갈리고
`doctor` 가 그 차이를 「불일치」로 보고한다 → [OPS-20].

**시각을 파라미터로 주입하는 규율이 `usage.ts`·`migrate.ts`·`tokens.ts` 에는 적용돼 있고
`gate.ts` 에는 없다.** 같은 규율의 부분 적용이 이 결함의 뿌리다.
