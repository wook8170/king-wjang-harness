- 후보 B(허용 목록 확대)는 `config/`·`.github/`·`Makefile`… 끝없는 두더지잡기이고, 목록 밖 정상 파일에서 과차단이 계속 재발한다.
- 그래서 (1) 프로파일 `source_globs`(스택별 정의는 프로파일 몫, §9) + (2) **소스 코드 확장자 44종**(프로파일이 얇을 때의 바닥)의 2단. 둘 중 하나라도 걸리면 deny, 아니면 allow.
