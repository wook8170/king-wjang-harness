# Privacy policy — king-wjang-harness

Last updated: 2026-11-05

king-wjang-harness is a Claude Code plugin made of hooks, a command-line tool and a local MCP server. All of them run on your own computer.

- **Data collected:** none. The plugin has no telemetry, no analytics and no server of its own.
- **Data sent:** none. The hooks, the CLI and the MCP server load no network module.
- **Data stored:** the plugin writes only to the `.harness/` directory of a project where you turned it on. Those files stay there until you delete them. In a project without `.harness/`, the hooks exit at once and store nothing.
- **Downloads:** Claude Code installs the plugin's npm packages when it installs the plugin. Optional companion plugins are installed only after you agree. Those tools follow their own privacy terms.
- **Children:** the plugin is a developer tool and is not directed at people under 18.

Questions: open an issue at https://github.com/wook8170/king-wjang-harness/issues.
